BasketStats - Pruebas AJAX

HTML de pruebas para los endpoints existentes de nuestra API. Utiliza Axios, datos editables y muestra la respuesta del servidor.

Atención: la URL inicial es producción. Crear, editar, eliminar o cambiar de plan modifica la base de datos real. Los botones de eliminación piden confirmación.

Configuración y sesión

Para probar el backend local, cambiar por http://localhost:3000/api/v1 y ejecutar el servidor.

Sin iniciar sesión

1. Registro y login

Si devuelve 409, cambiá username y email. Después podés iniciar sesión con ese usuario.

Para probar rutas de administrador, iniciá sesión con una cuenta admin. El token se guarda solo en memoria mientras esta página está abierta.

2. Categorías (crear, modificar y eliminar: solo admin)

Al listar, se completa automáticamente el ID con la primera categoría, si el campo está vacío. Revisalo antes de editar o eliminar.

3. Equipos (crear, modificar y eliminar: solo admin)

4. Jugadores (crear, modificar y eliminar: solo admin)

5. Partidos (usuario autenticado)

Para completar IDs automáticamente, ejecutá primero GET /teams y GET /categories. Para crear un partido se necesitan dos equipos diferentes. El plan Plus permite hasta 4 partidos.

6. Plan Plus / Premium

Este endpoint actualiza el plan del usuario autenticado de Plus a Premium. No es una prueba reversible desde la API.

7. API externa

8. Algunas pruebas de error

El último caso requiere que hayas iniciado sesión y cargado un equipo y una categoría válidos. Los errores 403 y 404 se pueden comprobar con los botones normales usando un rol sin permiso o un ID inexistente.
